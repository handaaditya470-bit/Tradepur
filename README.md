# 📈 TradePur

TradePur is a **stock market analysis web application** that provides real-time US stock data with interactive charts.
It allows users to analyze stocks using advanced charts and track market trends easily.

🌐 **Live Website:**
https://tradepur.up.railway.app/

---

## 🚀 Features

* 📊 Real-time stock data
* 📈 Interactive TradingView charts
* 🔐 Email OTP based authentication
* ⭐ User watchlist system
* 📉 Market trend visualization
* 🌐 Responsive web interface

---

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/handaaditya470-bit/Tradepur.git
cd Tradepur
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the development server:

```bash
python manage.py runserver
```

Open in browser:

```
http://127.0.0.1:8000
```
